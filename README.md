# Kiran Video Style Web — Vercel Ready

## Vercel settings
- Framework Preset: Other
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`
- Root Directory: `./`

Everything is in this one folder.

## Local
Run:
`npm install`
then:
`npm run build`
