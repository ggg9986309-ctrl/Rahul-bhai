# Kiran Video Style Web — Render Ready

## Render Web Service
- Build Command: `npm install && npm run build`
- Start Command: `npm start`
- Environment: Node
- No Publish Directory is required for a Web Service.

## Render Static Site alternative
- Build Command: `npm install && npm run build`
- Publish Directory: `dist`
- No Start Command.

Everything is in this ONE folder.
